# C Programming Series

A collection of C programming concepts, examples, and problem-solving exercises from Basic to Advanced level.

## Topics Covered

1. **C Basics** – Variables, Data Types, Input/Output, Type Casting
2. **Operators** – Arithmetic, Relational, Logical, Bitwise Operators
3. **Conditional Statements** – If-Else, Nested If, Switch
4. **Loops** – For, While, Do-While, Break, Continue
5. **Pattern Programs** – Star Patterns, Number Patterns, Floyd's Triangle
6. **Functions** – Function Basics, Arguments, Return Values, Recursion
7. **Arrays** – 1D Array, 2D Array, Searching, Sorting
8. **Strings** – String Basics, String Functions, String Manipulation
9. **Pointers** – Pointer Basics, Pointer Arithmetic, Pointer to Pointer
10. **User Defined Data Types** – Structures, Unions, Enums, Typedef
11. **Dynamic Memory Allocation** – malloc(), calloc(), realloc(), free()
12. **File Handling** – File Reading, Writing, Opening and Closing

## Tools & Technologies
- Language: C
- Compiler: GCC
- IDE: Visual Studio Code

## Purpose

To strengthen C programming fundamentals, improve logical thinking, and develop problem-solving skills through regular practice.
